# 本地第一版迭代记录

项目：`paper-plot-library`；网站：论文绘图案例库；版本：`0.1.0`。
检查日期：2026-10-11。原衰老文献日报未修改；未上传、推送或部署到 GitHub。

用户将“至少3轮”改为“多轮直到没有明显问题”，因此实际采用六个检查阶段。
下面区分合成测试、真实公开接口测试和浏览器检查，不把其中一种代替另一种。

## 第一轮：模块与配置

完成独立入口、网络访问、文献来源、图像/补充文件、静态代码、期刊/AI注释和前端。
修复损坏/未来时间缓存、无效请求参数、过大响应、非有限JSON、截断读取与安全错误信息。
NCBI和EasyScholar限速及失败重试计入预算，密钥不出现在配置对象打印中。
阶段检查点：84项离线测试通过。

## 第二轮：完整自动链与恢复

使用临时目录的合成文献、JATS、GitHub响应、图像、补充文件和AI响应，串联实际传输层到网站。
覆盖每天最多5篇、重复DOI、重复运行、中断后的配额恢复、失败单篇隔离、撤稿移除及AI预算。
修复未入选论文提前调用AI、旧种子抢占新案例AI预算、未核正式版本可被误标就绪的问题。
保持原选图输入文档与全仓库自动输入候选分开。阶段检查点：96项通过，继续增加恢复回归用例。

## 第三轮：真实公开来源

对PRC2-AgeIndex和DiMeLo-seq做精确DOI查询和公开PMC来源检查；没有调用付费AI或运行作者代码。
发现“Figure 1c”未正确识别，以及全角中文括号/主图、扩展图、补充图的编号混淆，已修复。
PRC2展示官方整张Figure1，800×579像素、CC BY4.0；不把整图误称为已核验的c分面截图。
补充PDF加入结构、页数和身份标志检查；ZIP不解包。阶段检查点：115项通过。

## 第四轮：独立交付审查

修复空哈希互相相等导致错误审批、其他脚本输入冒充当前输入、损坏账本继续写入和历史无限增长。
正式核查绑定审核人/时间、固定提交、脚本哈希、原图哈希、输入哈希和该输入实际读取脚本链接。
分类建议对象保持原始不确定性注释，不因`set()`遇到对象而崩溃，不自动进入正式选择目录。
作者代码声明按语句区分，避免把论文引用的工具仓库误认成作者脚本；补充“freely accessible”真实表达。
原始JATS无图号时不按顺序补造图号；保留原MIT版权声明。
原图署名保留JATS中提供的真实作者，而非仅写“论文作者”。
发布仅使用白名单导出，私有缓存/补充材料/用户放入预览目录的其它文件不随网站发布。
阶段检查点：136项通过。

## 第五轮：可用性和真实检索回查

桌面改为固定双列、820px以下单列，详情页与原图查看器加宽。
原图保持比例；标签/放大按钮位于图片下方，不遮盖坐标、图例；支持适应窗口和100%原始尺寸。
修复Logo返回首页和重复读屏播报。宽屏与手机检查结果见验收记录。

真实仅元数据检索首次返回9条正式候选，但全部为未来刊期；这会挤掉较早的可用文献。
修正为请求之前按UTC当天加刊期上限，返回后再作未来日期防守筛查，并提高作者代码检索约束。
继续复测发现无DOI的PMC记录也会占满第一页，已在分页前限制到带DOI的PubMed正式记录并排除综述。
最终真实元数据检索：1次请求返回10条正式候选，日期2026-10-01至2026-10-04；未下载它们的论文或代码。
`update --doi`现在只修补指定已有论文，不会额外发起全库发现；无效DOI在请求前拒绝。
