# Third-party sources and terms

The journal response projection and cache design adapt concepts from
[aging-sequencing-daily / meta.seubiomed.com](https://github.com/yin-huamin/meta.seubiomed.com),
MIT licensed. It is a separate implementation, not an import that runs the aging site's scripts.

The 50 initial records migrate the user's existing, source-grounded plotting-paper
research. They are curated candidates, not 50 executed reproductions. Author code
is accessed read-only for static inspection; installations, notebooks and scientific
objects are never executed. Public output uses fixed-version links and field/path
observations, not complete author-code copies. Unknown code license -> link only.

Original figures are obtained from [NLM PMC OA Cloud](https://pmc.ncbi.nlm.nih.gov/tools/pmcaws/)
and retain article-specific attribution, source URL, checksum and CC license link.
The site is not endorsed by NLM/NIH. A snapshot's retrieval date is not a guarantee
that it is the latest article version. v1 auto-publishes only CC BY / CC0 images
without observed third-party exclusions; NC, ND, SA, TDM and unknown terms are
conservatively linked, not rehosted. See [PMC copyright](https://pmc.ncbi.nlm.nih.gov/about/copyright/).

Supplement files are private local downloads, never part of the public site or
GitHub publication set. Archives are checked without extraction. An original image
of 800 pixels is labelled by its real dimensions, not advertised as publisher HD.
Automatic cropping requires a reviewer-approved, licensed bounding box.

Metadata: Europe PMC / NCBI PubMed / Crossref. Citation observations: OpenAlex,
with retrieval timestamps and nullable normalized metrics. IF/JCR/CAS: user's
EasyScholar account and its service terms. Indicator year remains unknown if
not supplied by the API. AI commentary: user's explicitly configured LLM;
generated learning notes require review and are not reproduction evidence.
